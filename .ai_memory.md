# pi-H3 MLX — memory

- 2026-11-22: Project started. M3 Max 128 GB; internal disk nearly full (13 GB free) → everything on exFAT SSD
  `/Volumes/1T ssd/pi-h3-mlx`, venv on internal `~/.venvs/pih3`. Network ~2-10 MB/s → aria2c, resumable.
- H3 text encoder tensors are byte-identical to `Qwen/Qwen3-VL-32B-Instruct` (sampled 5 tensors), pruned to 51 layers.
- pi-H3 adapter = full overrides (adaln weights, norm_out, heads, 4 blocks) + rank-64 LoRA (scale 1) fused at convert.
- Precision choice: AdaLN modulation computed in fp32 then cast (diffusers-pruned style), heads in fp32.
- MLX 8-bit quantized matmul is ~3.5x slower than bf16 at these sequence lengths → bf16 default.

  attention (attention dominates at 768p/10 s).
