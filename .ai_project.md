# pi-H3 MLX — project conventions

Port of pi-H3 (few-step MiniMax H3 text/image-to-video+audio, LakonLab) to Apple MLX for Apple silicon.

## Locations
- Root (external exFAT SSD): `/Volumes/1T ssd/pi-h3-mlx`
  - `pih3_mlx/` — this project (git repo); Python package in `pih3_mlx/pih3_mlx/`
  - `LakonLab/` — upstream reference code (read-only)
  - `diffusers/` — diffusers main with MiniMax H3 reference code (read-only)
  - `models/` — original HF weights (being downloaded by `download.sh`, aria2c, resumable)
    - `models/MiniMax-H3-Pruned/{transformer,text_encoder}`
    - `models/MiniMax-H3/{vae,audio_vae,tokenizer,processor,scheduler,audio_scheduler}`
    - `models/pi-H3/pi_h3_{2,4}step[_dwd]_adapter`
  - `models_mlx/` — converted / quantized MLX weights (created by `pih3_mlx/convert.py`)
- Python env: `~/.venvs/pih3` (Python 3.12, internal disk; exFAT breaks venvs). torch 2.15 (CPU/MPS, reference only),
  transformers 5.24, diffusers 0.44.dev (installed from the local clone), mlx 0.32.4, mlx-vlm 0.8.
- exFAT gotchas: macOS writes `._*` AppleDouble files; never rely on symlinks; `find . -name '._*' -delete` if a tool chokes.

## Module ownership (one file per component)
| File | Component | Reference source |
|---|---|---|
| `layout.py` | packed `[text, cond, audio, video]` sequence, RoPE positions, row timesteps, canvas/frame math | `diffusers/.../modular_pipelines/minimax_h3/{before_denoise,modular_pipeline}.py` |
| `transformer.py` | pruned H3 transformer (adaln_rank=8 time table) + LoRA fusion + DWD feature output | `LakonLab/.../diffusers/minimax_h3.py`, `diffusers/.../transformer_minimax_h3.py` |
| `dwd_head.py` | `SolH3DWDHead` pixel decoder (8 Sol window-attention layers) | `LakonLab/.../sol_h3/*.py`, `dwd_head.py` |
| `scheduler.py` | FlowEulerODEScheduler | `LakonLab/.../schedulers/flow_euler_ode.py` |
| `text_encoder.py` | Qwen3-VL conditioner, `hidden_states[50]`, keyframe presentation | `diffusers/.../minimax_h3/encoders.py`, mlx-vlm `qwen3_vl` |
| `audio_vae.py` | H3 audio VAE decoder (latents -> waveform) | `diffusers/.../autoencoder_kl_minimax_h3_audio.py`, `minimax_h3/decoders.py` |
| `video_vae.py` | H3 video VAE encoder (keyframes -> condition latents) + keyframe preprocessing | `diffusers/.../autoencoder_kl_minimax_h3.py`, `minimax_h3/{encoders,before_encoder}.py` |
| `pipeline.py` | end-to-end T2V/I2V/FLF2V + audio | `LakonLab/lakonlab/pipelines/pipeline_minimax_h3.py` |
| `convert.py` | HF safetensors -> MLX safetensors (+ optional quantization) | — |

## Code conventions
- MLX modules subclass `mlx.nn.Module`; inference only, no training code.
- Default compute dtype bfloat16; keep norms/softmax/timestep math in float32 where the reference does.
- MLX convs are channels-last (NHWC / NDHWC): convert torch conv weights `(O, I, *k)` -> `(O, *k, I)`.
- Each module exposes `sanitize(weights: dict) -> dict` mapping original HF keys/layouts to the MLX module, and a
  loader that reads safetensors with `mx.load` (lazy) so 40-60GB checkpoints never need 2x memory.
- Performance: `mx.fast.scaled_dot_product_attention`, `mx.fast.rms_norm`, `mx.fast.layer_norm`, fused ops,
  `mx.compile` where shapes are static, no Python loops over tokens, `mx.eval` once per block/step.
- Files stay under 800 lines.

## Testing
- `cd pih3_mlx && ~/.venvs/pih3/bin/python -m pytest tests -q`
- Parity tests build the PyTorch reference module (diffusers/LakonLab code) with a **small random config**, copy its
  state dict through the module's `sanitize`, and compare outputs in float32 (report max abs / relative error).
  Real-weight checks are added once downloads finish.
